所要時間の目安：①〜③の準備は最初の1回だけで、合わせて30〜60分程度です。一度終われば、次回からは③からすぐに始められます。漫画が完成するまでは、ページ数にもよりますが1回あたり10〜20分程度かかります（1ページにつき2〜3分）。
BEFORE YOU START

2. はじめる前に

この先、見慣れない言葉がいくつか出てきますが、覚える必要はありません。 それぞれ「何をするためのものか」だけ分かれば十分です。下の表にまとめたので、本文を読んでいて「？」と思ったら、ここに戻ってきてください。

用語ミニ辞典

ターミナル （Windowsでは「コマンドプロンプト」）
パソコンに文字で指示を出すための画面です。普段使うことはほとんどありませんが、最初の準備のときだけ少し使います。黒っぽい画面が出てきても、壊れたわけではありません。
Node.js（ノードジェイエス）
マンガクルを動かすための「土台」になる、無料の共通ソフトです。家を建てる前の基礎工事のようなものだと思ってください。
Claude Code（クロード コード）
マンガクルを実際に動かす本体です。あなたがテーマを話しかける相手になります。
Codex CLI（コーデックス シーエルアイ）
漫画の絵を実際に描いてくれる部分です。裏側で動いていて、あなたが直接操作することはほぼありません。
CLI （コマンドラインツール）
「文字を打って操作するタイプのソフト」をまとめて呼ぶときの言葉です。Claude CodeもCodex CLIも、この仲間です。難しく考えなくて大丈夫です。

マンガクルはMac・Windowsのどちらでも使えます。このあとの手順では、両方のやり方をそれぞれ書いています。

WHAT YOU NEED

3. 準備するもの

マンガクルは、あなた自身が契約する2つの月額制サービスの力を借りて動きます。これはマンガクル自体の料金ではなく、それぞれの公式サービスへの契約です。

ChatGPT Plus OpenAI社の公式サービス。漫画の絵を描く力になります。OpenAIの公式サイトから契約できます。
Claude Pro Anthropic社の公式サービス。あなたとチャットで会話する力になります。Anthropicの公式サイトから契約できます。
ポイント：料金プランは変更されることがあるため、最新の金額は必ずそれぞれの公式サイトでご確認ください。この2つ以外に、マンガクル自体への追加料金は発生しません。
INSTALL

4. インストール手順

ここから実際の準備です。上から順番に、ひとつずつ進めてください。全部で4つです。

A

Node.jsを入れる

何のため：マンガクルを動かすための土台を用意します。

Mac の場合

  1. nodejs.org を開く
  2. 「推奨版（LTS）」と書かれたボタンをクリックしてダウンロード
  3. ダウンロードしたファイルをダブルクリック
  4. 画面の指示どおりに「続ける」「インストール」を押していく

Windows の場合

  1. nodejs.org を開く
  2. 「推奨版（LTS）」と書かれたボタンをクリックしてダウンロード
  3. ダウンロードした .msi ファイルをダブルクリック
  4. 画面の指示どおりに「Next」「Install」を押していく
確認方法：ターミナル（Windowsはコマンドプロンプト）を開いて、次を入力しEnterキーを押します。 
node --version
数字（バージョン番号）が表示されれば成功です。
うまくいかない時は：何も表示されない、または「command not found」のようなエラーが出る場合は、一度パソコンを再起動してからもう一度お試しください。
B

Claude Codeを入れる

何のため：マンガクルを実際に操作する本体を用意します。

ターミナル（コマンドプロンプト）に、次を1行ずつ入力してEnterキーを押します。

npm i -g @anthropic-ai/claude-code

少し時間がかかります。文字がたくさん流れますが、止めずにそのまま待ってください。終わったら確認します。

claude --version
はじめてのログイン：この後マンガクルを初めて起動すると、自動でブラウザが開き、Claude Proのアカウントでログインするよう求められます。案内に沿ってログインすれば完了です。一度ログインすれば、次回からは不要です。
C

Codex CLIを入れる

何のため：漫画の絵を実際に描く部分を用意します。

npm i -g @openai/codex

終わったら、ログインのコマンドを入力します。

codex login
ブラウザが自動で開くので、ChatGPT Plusのアカウントでログインしてください。一度ログインすれば、次回からは不要です。
D

Pythonの道具をそろえる

何のため：画像の確認や、完成ページを1冊のPDFにまとめる作業を自動で行うための道具です。

pip install Pillow
うまくいかない時は：「command not found」と出る場合は、代わりに pip3 install Pillow をお試しください。
GET STARTED

5. マンガクルを使えるようにする

  1. LINEから届いたZIPファイルをダブルクリックすると、自動で展開されます（Windowsの場合、右クリック→「すべて展開」が必要な場合があります）。
  2. 展開してできた「mangakuru」という名前のフォルダを、デスクトップなど分かりやすい場所に置いてください。

起動する

mangakuruフォルダの中にある、次のファイルをダブルクリックします。

Mac

start_mac.command

Windows

start_windows.bat

初回に警告が出ることがあります：「開発元が確認できないため開けません」のような表示が出ても、故障や危険ではありません。初めて使うソフトに対する、念のための確認です。
Macの場合：ファイルを右クリック（またはControlキーを押しながらクリック）→「開く」を選択→表示された画面でもう一度「開く」を押してください。
Windowsの場合：「詳細情報」をクリック→「実行」を選択してください。
HOW TO USE

6. 実際に使ってみる

起動すると、黒っぽい画面（ターミナル）が開きます。少し待つと、その中にチャット画面が立ち上がります。画面の下の方に、文字を入力する欄があります。

話しかけてみる

入力欄に、作りたい漫画のテーマを伝えてください。例えばこんな風に打ち込みます。

「"猫カフェで働くロボットの物語"というテーマで漫画を作って」
「"〇〇（自分の商品名）"の魅力を伝える漫画を作って」
「"Kindle出版サポート"というテーマで営業資料用の漫画を作って」

聞かれることに答える

続けて、いくつか質問されます。難しく考えず、そのときの気分で答えて大丈夫です。

  • 総ページ数：迷ったら、まずは「4ページ」のように短めで試すのがおすすめです。
  • カラーか白黒か：お好みで選べます。SNSなどで目を引きたい場合はカラーが人気です。
  • キャラクターの要望：特になければ「おまかせで」で問題ありません。

できあがるのを待つ

1ページ作るのに2〜3分かかります。その間、画面には文字が流れ続けますが、これは正常に動いている証拠です。途中で画面を閉じたりせず、そのままお待ちください。

もし本当に止まってしまったように見えたら、入力欄に「続けて」と打ち込んでみてください。それまでの作業が失われることはありません。

YOU'RE DONE

7. 完成したら

完成すると、mangakuruフォルダの中の「output」フォルダの中に、テーマの名前がついたフォルダができています。その中にある final_book.pdf というファイルが、完成した漫画です。ダブルクリックすれば開いて読むことができます。

TROUBLESHOOTING

8. こんな時どうする？

症状から探せるようにまとめました。当てはまるものを探してみてください。

急に真っ黒い画面が出てきた
それがターミナルです。故障ではありません。閉じずに、そのまま待っていてください。
英語のエラーのようなものが表示された
多くの場合、インストール手順のどこか一つが完了していないサインです。「4. インストール手順」を上から見直してみてください。
何も反応がなく、フリーズしたように見える
漫画の絵を作成している最中の可能性が高いです。1ページあたり2〜3分かかるので、数分待ってみてください。
テーマを伝えても質問されず、いきなり変な画像が1枚だけ出てきた
mangakuruフォルダの正しい場所から起動できていない可能性があります。フォルダの中身をフォルダごと動かさず、展開した「mangakuru」フォルダの直下で起動し直してみてください。
チャット欄に何を打てばいいか分からなくなった
「6. 実際に使ってみる」にある例文をそのままコピーして貼り付けてみてください。
FAQ

9. よくある質問

OpenAIのAPIキーは必要ですか？
不要です。画像生成はCodex CLI経由でChatGPT Plusのログインだけで行われます。
Windowsでも使えますか？
Mac・Windowsどちらでも利用できます。このガイドでは両方の手順を併記しています。
途中で止まってしまいました
「続けて」と入力してください。進行状況は自動で保存されているので、途中からでも再開できます。レート制限に達した場合は、少し時間をおいてから同様に「続けて」と伝えてください。
カラーと白黒、どちらを選べばいいですか？
好みで選べます。SNSでの集客・発信用にはカラーの方が目を引きやすく、じっくり読ませる読み物にはモノクロの落ち着いた雰囲気も好まれます。
ページ数に上限はありますか？
ありません。1回の実行で作れる枚数を超える場合は「続けて」と伝えれば、何回でも継続して長編が作れます。

動作にはChatGPT Plus・Claude Pro相当のご契約が必要です（本ツール自体に追加のAPI課金はありません）。ご不明な点はLINE公式アカウントよりお問い合わせください。
